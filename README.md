## Depots et tickets

Pour activer les depots, executer le contenu de
`supabase/migrations/20261022100000_depots.sql` dans l'editeur SQL du projet
Supabase. Ensuite, executer `supabase/tests/isolation.sql` dans le meme editeur
pour verifier l'isolation et les operations de depot. Le test affiche un tableau
de resultats puis annule ses donnees avec `ROLLBACK`.

La creation d'un depot recalcule les prix depuis le catalogue en base. Les
montants et dates du ticket restent figes selon les regles de la migration.
